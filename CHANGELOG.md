# Changelog

Полная история изменений ASCII Pets. Коротко о свежем релизе — в [README.md](README.md).

## [1.1.0] — 2026-09-23

- **Три питомца**: `MAX_PETS` 2 → 3, третий селект в настройках, окно статуса тянется под 1–3 петов.
- **Социалки**: парные `sniff / dance / race` (были только `play / chase / squabble`) и тройные `huddle / parade` (кластер, свой кулдаун, приоритет над парами); сцены 2–4 с с хореографией, звуками и влиянием на настроение **и** энергию; кулдауны по парам.
- **Окно настроек** (frameless-карточка): питомцы ×3, стиль, размер, монитор, поведение; открывается из меню («Настройки…») и кнопкой ⚙ в окне статуса. Меню ужато до Погладить / Покормить / Пауза / Настройки / обновления / Выход. Окно подгоняет высоту под содержимое.
- **Выбор монитора** для полосы (`displayId`, по умолчанию primary, откат при отключении); статус и сэмплер следуют за выбором.
- **Стиль ASCII 4 — пиксель**: генератор `scripts/pixel-art.py` (кадры + `assets/pixel-*.png`), цветные фиксированные палитры, общий силуэт тени, рисовка на канвасе бесшовно (петы и кучки), выход из авто-инверсии.
- **Звуки всех событий** (WebAudio-синтез): прыжки, тихие шаги, еда, какашки, уборка, глажение, испуг, приветствие, храп, урчание, драг/бросок, джинглы социалок — тембры по скинам; громкость поднята.
- **Песни**: редко (раз в ~5 минут) пет поёт одну из 2–3 своих мелодий своим голосом, ноты ♪ уплывают вверх (`shared/songs.ts` + тест).
- **Реакции**: бросок с инерцией (−энергия), подозвать двойным кликом, отпор при переглаживании (6-й пат за 10 с: −настроение), побудка кликом по спящему (45 с).
- **Кучки**: до 2 на пета (сдвиг, персист массивом с миграцией), появление/исчезновение с затуханием (150 мс), гниение настроения ×N.
- **Нужды**: сон восстанавливает энергию (темп отдыха 6 → 9/мин); выносливость по скинам — пёс 0.7, кот 1.0, лягушка 1.4.
- **Производительность**: сэмплер пропускает статичные кадры + автодеградация интервала (2 с → до 5 с), тишина на паузе, тамбнейл 640×360; инкрементальный `paintInk` (только изменившиеся клетки); минификация бандлов (`renderer.js` 113 → ~90 КБ); `npm run start:fast` (сборка без typecheck); опциональный FPS-счётчик в окне статуса.
- **Поверх всех окон**: перезаявление уровня (создание, смена геометрии, blur, таймер 30 с) + `moveTop()`; виртуальные столы (`setVisibleOnAllWorkspaces`); single-instance (вторая копия открывает настройки).
- **Автообновление** реально уехало в сборку (16 пакетов в `files`), отказы без конфига глотаются тихо.
- **Арт-фиксы**: лапы собаки без мигания (поднятая лапа тоном, потом без чередования в цикле); симметричные скины без зеркального дёрга; боб на рыси убран, X снаппится; `flat`-класс применяется и на холодном старте (`applyStyle`).
- Окно статуса подгоняет высоту под содержимое; `buildStamp`-диагностика прожила один релиз и удалена.

## [1.0.0]

Базовый выпуск (реконструкция: всё, что не перечислено в 1.1.0).

- Питомцы кот / пёс / лягушка (ходьба, прыжки лягушки по параболе, кваканье), **до 2 питомцев**.
- Стили рисовки ASCII 1 — классика, ASCII 2 — блоки, ASCII 3 — тамагочи.
- Все настройки — пунктами контекстного меню / трея (питомцы, стиль, размер, пауза, поверх окон, инверсия, уведомления, звук, автозапуск).
- Фиксированное окно статуса (карточки, ♥/🍖/💩/✕).
- Нужды голод / настроение / энергия + `localStorage` + офлайн-догон до 8 часов (плоский расход, отдых только на паузе).
- Звуки: голос скина, еда, какашка; чекбокс mute.
- Парные социалки `play / chase / squabble` (один прыжок + сообщение).
- Одна кучка на пета, уборка кликом, гниение настроения.
- Только primary-монитор; авто-инверсия с семплером раз в секунду.
- Базовый always-on-top (`screen-saver` раз при создании), автозапуск (в пакете), код автообновления без бандлинга зависимостей.
