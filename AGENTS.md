# AGENTS.md

- Project: Electron desktop pets (`ASCII Pets`). All graphics are ASCII-art — no image/sprite assets. Pet lives in a full-width transparent strip hugging the taskbar edge, above it.
- Prereqs: Node.js 20+, Windows (positioning targets the Windows taskbar). First `npm start` downloads the Electron binary and first `npm run dist` fetches NSIS tools — both can take minutes; don't treat as a hang.
- Stack: TypeScript + Electron (v44). No lint/CI, no `opencode.json`.
- Build (`npm run build`, also run by `npm start` / `npm run dist` / `dev`): `build:main` = `tsc` emits `src/main.ts`+`src/preload.ts`+`src/shared/**` -> `dist/`; `check` = `tsc --noEmit -p tsconfig.check.json` typechecks all of `src/` (renderer errors surface only here — fastest verification); `build:renderer` = esbuild IIFE bundle `src/renderer/renderer.ts` -> `dist/renderer/renderer.js` + copy `index.html`. Tests: `npm test` (builds main, runs `node --test` on `test/*.test.mjs`, no deps). Dev: `npm run dev` (`scripts/dev.js`, stdlib-only watch; restarts Electron only on main/preload/shared changes).
- Pure/tested logic lives in `src/shared/`: `pet-stats.ts` (hunger/mood/energy math, no I/O), `placement.ts` (`bounds` vs `workArea` taskbar-edge detection), `skins.ts` (skin registry — id, `moves: walk|hop`, `petSound` — `normalizePack`, `MAX_PETS=2`), `temperament.ts` (CALM/WILD presets incl. hop ranges, pure `rollGait`/`jitterTemperament` — randomness injected), `color.ts` (pure invert/median/css + `frameCells`/`cellCenter`/`CellInk` for per-cell inversion), `ipc.ts` (the `PetSnapshot` main↔renderer contract — single source of truth). Tests import compiled `dist/shared/*.js` — keep these modules free of Electron/DOM imports. `test/skins.test.mjs` additionally bundles `src/renderer/ascii.ts` via the esbuild API and asserts every registered skin has walk×4 + happy/hungry/sleep/jump pairs + blink/eat, each frame 5 non-blank lines.
- Renderer has no Node (`contextIsolation: true, nodeIntegration: false`): never ship CommonJS `require()` there or the window stays invisibly empty. Only bridge is `window.petAPI` from `src/preload.ts` (`setClickable`, `showMenu`, `getPack`, `pushStats`, `onPetAction`, `onPetFeed`, `onPetGreet`, `onPetStartle`, `onSetPack`, `onSetColorMode`, `onSetPaused`, `onSetInkColor`). Pack (skin id per slot) is owned by main via `settings.json`; renderer renders `["cat"]` instantly then reconciles via `getPack()`/`set-pack`. Needs persist in `localStorage` via `src/renderer/pet-store.ts` (per-slot keys, 8h offline catch-up cap); renderer pushes needs snapshots via `pushStats` (`PetSnapshot`: measured text origin `ox/oy` + char cell + grid cols/rows) for the tray tooltip and the per-cell inversion sampler (main never hardcodes renderer CSS metrics); app settings (`pack`, `colorMode`, `onTop`, `openAtLogin`) persist in `%APPDATA%/ASCII Pets/settings.json` from `main.ts` (first launch migrates settings + needs from the old `ASCII Companion` locations). Autostart applies only when `app.isPackaged`.
- Window contract (don't regress): strip from `screen.getPrimaryDisplay()` via shared `stripBounds()` (`PET_H=180`, `BOTTOM_MARGIN=8` in `main.ts`); `transparent: true, frame: false`, `setAlwaysOnTop(true, "screen-saver")` (= above taskbar on Windows; `floating` hides behind it), `skipTaskbar: true`. Click-through by default via `setIgnoreMouseEvents(true, { forward: true })`; renderer re-enables mouse events only on pet hover (`set-clickable` IPC). Never make the whole strip clickable — it would block the taskbar.
- ASCII rule: all art lives in `src/renderer/ascii.ts` as `SKINS` (`cat`, `dog`, `frog`); `renderer.ts` (multi-`Pet` class, one element per pack slot) only picks frames, never hardcodes art. Hoppers (`moves: "hop"`) never glide — X interpolates along the jump parabola in `hopStep()`; frog also croaks spontaneously via `croakUntil` + the `eat` frame. Icons: `assets/icon.{png,ico}` (window/exe) + `assets/icon-16.png` (tray) are generated — regen via `python scripts/make-icon.py`, don't hand-edit binaries. Tray (`main.ts`, same `menuTemplate()` as the pet context menu) is the app's only system presence — `skipTaskbar: true` hides the strip; destroy it on `before-quit`.
